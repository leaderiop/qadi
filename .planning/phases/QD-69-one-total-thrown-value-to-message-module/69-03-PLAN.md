Design recorded (owner: choose the most complete and clean design and record why):
- The order is D-04's, written as two guarded reads and a fallback: read the `message` only of an `Error` (a plain
  `{ message }` object stays its `String` form, as every site renders it today), return it if it is a string; else
  return `String(thrown)` if that does not throw; else the placeholder. One `try` per read, so a throwing `instanceof`
  (a proxy's `getPrototypeOf` trap) is guarded too. The placeholder is a module constant, as `ValueText.ts` keeps
  `NO_JSON_FORM`.
- `describeThrown` and `renderReason` are deleted rather than kept as aliases: one name for one rule.
- The defect fallback reads `Cause.squash(cause)`, which returns the died value itself, so the fallback text is the
  same rule as the failure path. A normal defect keeps its `Cause.pretty` text.
- `PortWireEncode`'s catch arms take `thrownMessage` point-free (`catch: thrownMessage`).
- The overview row and the source doc comment cite ADR-QD-182 as plain text (no link): 69-05 lands the ADR file in this
  phase, and no gate resolves a plain ADR id (verify-traceability check 5 resolves links only).
