# Phase 49 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope.** A refactor with a **no-visual-change contract** (CONTEXT D-12, D-13). The `@qadi/devtools` Questions panel
(`packages/devtools/src/react/QuestionsPanel.tsx`) must render **byte-identical** text, markup, styles and `data-testid`s
for every input it renders today. What changes is where its rows come from:

- Before: `DevtoolsDock` passes a `gates` array (`DevtoolsDock.tsx:124, 339`) and the panel joins it to the polled
  questions in the view (`QuestionsPanel.tsx:96-97, 169`: `gateGroups`, `instancesAsking`).
- After: the dock model owns a `questions` store (D-10). Its one snapshot holds the joined question × instance rows and
  whether gates are absent or empty. The panel renders that snapshot and calls neither `gateGroups` nor `instancesAsking`.

The five gate-state words (`Failed`, `Denied`, `Rechecking`, `Pending`, `Allowed`) come from `@qadi/core` (D-01..D-04). The
words on screen do not change: `instance.state` is rendered raw, and the `DisplayState` mapping is unchanged.

**Design tokens: none added, none changed.** Every value below is an existing token from
`packages/devtools/src/react/theme.ts` or an existing inline literal in `QuestionsPanel.tsx`. No new screen, component,
glyph, state or interaction. The Phase 34 and Phase 36 dock contracts remain in force.

**The one host-facing change is not visual** (D-09, Breaking): `DevtoolsDock`'s `gates` prop becomes a structural registry
(`GateRegistryLike`, `{ subscribe, instances }`). See "Host-Facing Usage Change". It leaves one visible string stale, which
this contract flags as Open Question 1 rather than deciding silently.

> registry throws, so no existing input renders it and the characterisation is unchanged.

`undefined` versus `[]` in the view. Absent is a missing prop. Empty is a missing `instrument` on the provider. They have
different fixes, so the two messages must stay different.

## Behaviour Contract (what must hold, from the base)

Interaction is unchanged. These are the observable properties the characterisation tests pin and the refactor must keep.

1. **One row per question, instances nested** (BEH-QD-217). Rows follow `questions` order; the React key stays
   `${policyLabel(policy)}-${index}`. Instances under a row are in registry (mount) order. Grouping is by `Equal.equals` on
   policy and resource, so two equal policies are one row.
2. **Gates and questions are independent halves of one snapshot.** With `questions` undefined, the Gates block still shows
   its message or its pick button, as today. The snapshot must not collapse gates to "absent" because questions are absent.
3. **One moment.** Every row is the join of questions and instances read together at one publish (D-14, CONTEXT
   Specifics). No row shows a question from one poll beside instances from another.
4. **Same reference until something changes.** A publish with an equal join must not re-render the panel.
5. **Lens, pick, highlight unchanged.** `useLens` still receives the **flat** instance list (it highlights by id and picks by
   element), so the snapshot carries the flat list as well as the per-row instances; absent gates give `[]`. A pick sets
   `data-qadi-picked="true"` and scrolls the row into view (`scrollIntoView({ block: "nearest" })`). Picking stops on pick,
   on `Escape` and on unmount. Unmounting removes every `[data-qadi-lens]` overlay.
6. **Instrumentation off means absent** (AGENTS.md §13, D-16). No registry: nothing registers, no marker renders, and the
   panel shows the "No live guards were handed to the dock" message, with no pick button.
7. **Activity.** The model's scope closes when the dock is hidden and reopens when shown (`useDockModel.ts`). The first
   snapshot of a reopened model must read the registry's **current** instances, never rows retained from before the hide.
   A guard records that it exists, what it renders now and where, never a retained verdict (ADR-QD-053).
8. **An unknown state is shown, never dropped or coloured as an answer** (D-05). `GateInstanceLike.state` and `.kind` stay
   `string`; an unknown state renders its own name, muted, `data-treatment="Unrecognised"`.

## Interaction and Accessibility

No interaction is added or changed. The panel root keeps `diagnosticsRootProps(status)` and `data-testid="qadi-questions"`;
the dock body keeps the Phase 36 focus ring. The following test hooks are a **stable contract** and must not change:

`qadi-questions`, `qadi-keying-note`, `qadi-gates-absent`, `qadi-pick`, `qadi-questions-absent`, `qadi-questions-empty`,
`qadi-question-block`, `qadi-question`, `qadi-question-scope`, `qadi-question-unmounted`, `qadi-highlight`,
`qadi-instance` (with `data-qadi-picked`), `qadi-instance-state` (with `data-treatment`), `qadi-instance-unlocatable`,
`qadi-invalidate`, `qadi-hydration*`. Overlays keep `data-qadi-lens`.

The disabled highlight keeps its `title` as the reason a button is inert. Contrast ratios are those of the existing tokens
and are not re-derived (no colour changes).

## Open UI Questions (resolved 2026-11-16)

1. **One string goes stale: resolved by the user ("Update the clause").** The `gates === undefined` message's advice
   (`useGateInstances()` / `atoms.gates.instances()`) no longer type-checks after D-09. Only that clause changes, to
   `Pass gates — usually atoms.gates, from @qadi/react — to list who is asking.`, and the one assertion that includes
   `useGateInstances()` (`QuestionsPanel.gates.test.tsx`, "says where live guards come from when none were handed in") is
   updated in the same commit as the prop change. ADR-QD-162 names it as the phase's single deliberate copy edit (CONTEXT
   D-12a). Every other string stays byte-identical.
2. **Panel API shape: not a public surface.** `QuestionsPanel` is not exported (`packages/devtools/src/react/index.ts`
   exports `DevtoolsDock`, its props and hooks, not the panel), so its props are package-private. Whether it takes the
   snapshot as one prop or reads it through a hook is the planner's call, and it adds no Breaking line. The only public
   change is `DevtoolsDockProps.gates` (D-09).
3. **Snapshot owns the flat list.** Behaviour Contract 5 requires the flat instance list for `useLens`. Naming it is the
   planner's call; it must not be recomputed in the view.
