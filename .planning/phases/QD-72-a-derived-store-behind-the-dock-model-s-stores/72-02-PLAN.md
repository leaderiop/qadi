## The derived store's rules: `describe("makeDerivedStore")` in `ExternalStore.test.ts`

Each row is one `it.effect` with the exact title. "heard" counts a listener on the derived store subscribed after it
is built; "computed" counts the compute's calls; "closed" means built under `Scope.provide(…, scope)` on
`const scope = yield* Scope.make()` and then `yield* Scope.close(scope, Exit.void)`. A key input that is not a parent
is a `let` in the test, moved and then followed by `store.refresh()`; a parent is `makeExternalStore(…)` unless a row
says otherwise. Every compute returns a fresh object unless a row says otherwise, so a recompute is a new reference.

| # | Title | Feed | Expected |
| --- | --- | --- | --- |
| 1 | the first compute runs at construction and notifies no listener | one parent; key `{ value: parent.getSnapshot() }`; computed and heard counted | computed 1 after the build, with the initial key; the snapshot is that result; heard 0 |
| 2 | each field of a three-field key moved alone recomputes and notifies once | key `{ a, b, c }` read from three `let`s (`number`, `string`, `boolean`); one parent; for each field in turn: move it alone, then `refresh()` | after each move computed and heard each grow by exactly 1 (a loop over the three fields) |
| 3 | a one-field and a five-field key each recompute once when one field moves | two stores over one parent, keys of one and of five fields read from `let`s; move the one field and the fifth field, `refresh()` each | each store computed +1 and heard 1 |
| 4 | an unchanged key calls neither the compute nor any listener | key read from the parent; `parent.publish(parent.getSnapshot())` | computed stays 1; heard 0 |
| 5 | a repeat trigger after a change calls neither the compute nor a listener | key read from the parent; `parent.set(next)`, then `parent.publish(next)` | computed 2 and heard 1 after both |
| 6 | a key that loses a field holding undefined counts as changed | key type `{ readonly a: number; readonly b: undefined } \| { readonly a: number }`; the reader returns `{ a: 1, b: undefined }`, then (a `let` flipped) `{ a: 1 }`; `refresh()` | computed +1; heard 1 |
| 7 | a key that gains a field counts as changed | key type `{ readonly a: number } \| { readonly a: number; readonly b: number }`; `{ a: 1 }`, then `{ a: 1, b: 2 }`; `refresh()` | computed +1; heard 1 |
