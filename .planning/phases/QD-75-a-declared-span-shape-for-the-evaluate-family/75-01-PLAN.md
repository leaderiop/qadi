## ADR-QD-188 at Rev 1.0

File `spec/decisions/188-the-evaluate-familys-spans-are-declared-once-and-a-failed-span-says-what-was-asked.md`, title
`# ADR-QD-188 — The evaluate family's spans are declared once, and a failed span says what was asked`, Document
Control copied from ADR-QD-187's shape: Document ID `QADI-ADR-188`, Revision `1.0`, Effective Date `2026-11-23`, Status
`Accepted — extends ADR-QD-051 and ADR-QD-109`, Change History `1.0 (2026-11-23): Initial release (ARCH-122,
CCR-QD-467)`. Sections, in prose, numbered decisions, no D-number:

1. `## Context` — what the code before ADR-QD-188 wrote: a failed `qadi.evaluate` span carried only `qadi.outcome:
   "Failed"` and `qadi.error_tag`, so a tracer filtering by subject or evaluation id missed every failed evaluation;
   the outcome sat under `qadi.decision` on success and `qadi.outcome` on failure; the keys were hand-typed in
   `Lifecycle.ts`, `Predicate.ts`, `SubjectSet.ts` and `GuardHealthCheck.ts` and again in the tests; `toPredicate`
   annotated nothing when it failed and the probe never said what it asked. The port spans (ADR-QD-051, ADR-QD-109,
   BEH-QD-227) and the sink record (`SinkRecordFields.ts`, ADR-QD-135) already state their fields once.
2. `## Decision` — numbered: (1) one outcome key, `qadi.outcome`, closed values `Allow`, `Deny`, `Failed`, on every path
   of `qadi.evaluate`, and `qadi.decision` is removed; (2) no release writes both keys; the reasons for 1 and 2 as the
   orchestrator resolution lists them, and the sentence that both were decided autonomously under the owner's standing
   instruction ("do not ask me; always pick the most complete and clean solutions") in place of the roadmap's human
   checkpoint, before any source change; (3) one package-private module, `EvaluationSpan.ts`, beside `PortSpan.ts`,
   declares `evaluateSpan`, `toPredicateSpan`, `decideSubjectsSpan`, `decideSubjectsStreamSpan` and
   `guardHealthCheckSpan`, each `{ name, question, answer }` built with `spanStruct`, and the `denialEvent` struct; each
   key is spelled once there, and `qadi.subject_id` is read from `sharedQuestionKeys`; (4) the field table of
   `75-CONTEXT.md` D-05 (copy the keys per span, the closed outcome tied to the decision's tags plus `Failed`, the
   policy tag closed over the policy tags, every other field a string, number or boolean, no resource on any span,
   `qadi.decideSubject` keyless); (5) every question is annotated before the work it describes, on every path,
   and a failed translation's answer is its error tag; (6) one key per fact: only `qadi.evaluate` carries the outcome,
   `qadi.error_tag` is shared by the three spans that can fail, the obligations are comma-joined only on an allow that
   owes some, and the denial log line keeps its message and its three annotations, built from `denialEvent`; (7) each
   span's name is read from its declaration; (8) the keys are guarded by a house-style rule that reads the key set
   from the declaration (named in the What-enforces-it section added with the rule).
3. `## Alternatives considered` — rejected, each with its reason: keep `qadi.decision` and add `Failed` to it (a failure
   is not a decision, and the sink record says `outcome`); write both keys for one release (a second definition of one
   fact, and nothing here reads the old key); a declaration beside each writer (four places to spell one shared key);
   exporting the declaration (a host has no span of this family to write, AGENTS.md §9); the predicate tag as a closed
   literal list (the tags live in `Predicate.ts`, which reads this module, so the list would be a second copy or an
   import cycle).
4. `## Consequences` — breaking for a tracer query on `qadi.decision`, shipped with a `@qadi/core` changeset and an
   upgrade-guide section; every evaluation annotates twice (question, then answer), measured and recorded in a later
   revision; `decideQuestion` stays exported for its type test.
5. `## Related` — ADR-QD-051, ADR-QD-109, ADR-QD-135, ADR-QD-094, ADR-QD-123 (the metric-literal budget this rule's
   shape follows), BEH-QD-227, INV-QD-044.
