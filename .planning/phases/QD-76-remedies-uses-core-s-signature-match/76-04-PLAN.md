  cause })`, with a one-sentence comment: the event is set only when its schema admits the request's value, so a

  never `"Unknown"`; that rows and queries are keyed by `decisionHistoryPort.key`, whose text is injective (`PortKey.ts`)

  `actedAnswerFromEvents` both read it, so the layer and the judgement cannot answer differently.

  "decisionHistoryFromEvents", hasActed: (query) => Result.match(lookup(query), { onSuccess: Effect.succeed, onFailure:
