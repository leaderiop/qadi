## Flagged assumptions

- **A smuggled resource is written as `JSON.parse('{"resource":{"ownerId":"someone-else"}}')`** (RESEARCH A2): `JSON.parse`'s
  result is untyped, which is exactly the JavaScript caller the runtime defence is for, and it carries no `as` and no `any`
  token (`pnpm lint` confirms). It compiles before and after the refusal, which a typed value cannot.
- **`enforceProjected` stripping a runtime resource is in scope** (D-06: it "decides against … none"). It is a defect
  fix for untyped callers, the INV-QD-108 hazard at runtime, and reversible. It is the only RED case in this plan.
- **HAND-04's edge is unclassified** by the probe; it is carried as the backstop truth above, not dropped.
