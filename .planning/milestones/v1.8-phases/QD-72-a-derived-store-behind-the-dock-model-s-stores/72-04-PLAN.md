## The derived store in `ExternalStore.ts`

- Imports: `import * as Effect from "effect/Effect"` and `import type * as Scope from "effect/Scope"`.
- `export interface ReadableStore<A>` holds `subscribe` and `getSnapshot`, moved out of `ExternalStore<A>` with their
  doc comments; `export interface ExternalStore<A> extends ReadableStore<A>` keeps `set` and `publish`. One line of doc
  each: the read half a component or a derived store reads; the read half plus the two writes.
- `export interface DerivedStore<A> extends ReadableStore<A>` with `readonly refresh: () => void` (doc: reads the key
  again and recomputes when it moved; the trigger for a key input that is not a parent).
- `export type Parent = Pick<ReadableStore<unknown>, "subscribe">` (doc: what a derived store listens to).
- `function sameFields<K extends object>(a: K, b: K): boolean`, a module-private function declaration beside
  `sameElements`: a `for…in` over `a` returning false when a field is missing from `b` or differs by `===`, then a
  `for…in` over `b` returning false when a field is missing from `a`; true otherwise. One doc line: per-field identity
  over the union of both keys' own fields, the same identity `set` uses.
- `export const makeDerivedStore = Effect.fn("qadi.devtools.makeDerivedStore")(function* <K extends object &
  Required<K>, A>(options: { readonly parents: readonly [Parent, ...Array<Parent>]; readonly key: () => K; readonly
  compute: (key: K) => A }): Effect.fn.Return<DerivedStore<A>, never, Scope.Scope> { … })`. Body: `let held =
  options.key()`; `const store = makeExternalStore(options.compute(held))`; `let stopped = false`; `refresh` returns
  when stopped, reads `next = options.key()`, returns when `sameFields(held, next)`, computes `value`, assigns `held =
  next`, then `store.set(value)`; `const releases = options.parents.map((parent) => parent.subscribe(refresh))`;
  `yield* Effect.addFinalizer(() => Effect.sync(() => { stopped = true; for (const release of releases) release(); }))`;
  returns `{ subscribe: store.subscribe, getSnapshot: store.getSnapshot, refresh }`.
- Its doc comment: one line (a store computed from a key read off its parents and inputs, recomputed only when a field
  of the key changes identity, in the caller's scope); then: the order (on a trigger with an unchanged key nothing
  runs; otherwise compute, then commit the key, then `set`, so a throwing compute commits nothing and a compute
  returning the held reference notifies nothing); the ordering guarantee (its refresh is subscribed to the parents in
  the order listed, when it is built, so it moves before every listener subscribed after it); its listeners follow the
  listener contract above (pointed at, not restated); after the scope closes nothing is read or computed, `refresh`
  does nothing and the last snapshot stays; then what enforces what, in those words: the compiler refuses a key type
  with an optional field, an empty parent list and a compute reading a field outside its key; a test pins that each
  field moved alone recomputes once and that keys of other shapes compare the same way; a compute that reads state
  outside its key is checked by neither.
