## The per-store tests and the store-list test

Each per-store test is one `it.effect` holding a list of rows `{ field, move }` (a `ReadonlyArray` of a small
interface the test declares), looped with a fresh model per row; a second list of outside fields loops the same way
asserting no notification.

| Title | Rows: key field → how it is moved alone | Outside the key (no notification) | Order |
| --- | --- | --- | --- |
| the diagnostics store moves once per key field and not for gates or questions | the feed's snapshot → a collector answer that differs on the next tick under `{ diagnostics: { collector } }`, after `settleTurns`, then `tick`; the supplied reading → a `configure` with a new reading object | a guard added to the registry; a `configure` with a new `questions` thunk and the same reading | the diagnostics listener runs once per row |
| the questions store moves once per key field, before a diagnostics listener | the gates feed's snapshot → a guard added to the registry; the supplied questions → a `configure` with a new questions array; the unsampled flag → a poll with no supplied questions going from `Starting` to `Live` (as M32 b builds it) | a `configure` moving only the wiring | in the supplied-questions row, a diagnostics listener reads the recomputed questions snapshot |
| the services store moves once per key field, before a diagnostics listener | wiring, activity, call log → a `configure` with that field of the reading moved (`wiringNamed`, `activityOf`, `logOf`); the unsampled flag → the `Starting` to `Live` flip with every input supplied (as M53 builds it) | a `configure` moving only the hydration; one moving only the supplied questions | in the wiring row, a diagnostics listener reads `rowOf(model).state` of the new wiring |

Store-list test, `the members with subscribe and getSnapshot are the stores BEH-QD-700 names`: build a model with no
inputs, take `Object.entries(model)`, keep the names whose member has both `subscribe` and `getSnapshot`
(`Predicate.hasProperty`), and `assert.deepStrictEqual` the names with `["timeline", "dock", "explorer", "roles",
"simulation", "diagnostics", "timelineStatus", "questions", "services"]`, the one place the test writes the list.

Header: the count sentences become one sentence: the dock owns stores, listed once in BEH-QD-700 and checked by the
store-list test below, and the rules that connect them. Nothing else in the header changes.
