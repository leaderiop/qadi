## The rules

A block after the ADR-QD-123 metric block and before `[no-numbering-placeholder]`, opened by a comment in the metric
block's shape: ADR-QD-188, a span key of the evaluate family is declared once, in `EvaluationSpan.ts`, and read
through that declaration; three rules, none of them a new gate number (`pnpm lint` runs this script).

- `SPAN_KEY_DECLARATION = "packages/core/src/EvaluationSpan.ts"`, `SPAN_KEY_SHARED =
  "packages/core/src/PortSpanEncode.ts"`, and `SPAN_KEY_MIN = 11` with a doc comment: the size of the key set when the
  rule was written; an extraction that finds fewer keys fails, so a rename of the declaration cannot empty the rule.
- The key set: every `"qadi.<lowercase and underscores>"` literal on a line of the declaration that is neither a
  comment line (`isCommentLine`) nor a `name:` line (the span names), plus the `subjectId` value inside the
  `sharedQuestionKeys` object of `PortSpanEncode.ts`. No key is written in the script.
- `[span-key-source]`: fails, each with its own message naming the file, when the set is smaller than `SPAN_KEY_MIN`
  or the shared key cannot be read; when a key literal appears on more than one non-comment line of the declaration
  (spelled twice); when the declaration spells the shared key; and when any `srcSources` file other than the two holds
  a bounded mention of a family key (`qadi.` + key, not preceded by `[A-Za-z0-9_.$]` and not followed by
  `[A-Za-z0-9_.]`), comment lines included, or `PortSpanEncode.ts` mentions any family key other than the shared one
  once. The message says the key is read through `EvaluationSpan.ts` (ADR-QD-188).
- `SPAN_KEY_LITERAL_BUDGET`: `Readonly<Record<string, number>>` (the script's own JSDoc type, as for the metric
  budget), rows in path order, each with a one-line reason comment: the contract (the tracer-facing golden, written
  with literal keys on purpose); the five core port-span goldens and devtools `PortCalls.test.ts` (they pin the port
  spans' shared `qadi.subject_id`, a port key this rule does not convert); `CollectingTracer.test.ts` (an arbitrary
  attribute in a tracer test); devtools `Source.test.ts` (it pins that devtools' own log line carries no
  `qadi.reason`).
- `[span-key-literal]`: for each `testSourceSet` file, comment lines blanked, the count of an exact quoted family key
  (`"`, `'` or a backtick, the same quote closing it) not inside a `describe(`/`it(`/`test(`/`it.effect(`/
  `it.scoped(`/`it.live(`/`it.layer(` title (the `METRIC_ID_LITERAL` lookbehind), compared with the budget in both
  directions, with the two messages of `[metric-id-literal]` reworded for span keys (read a key with
  `decodeSpan`/`encodeSpan`/`struct.keys`; a literal key belongs in a golden, with its exact count).
- `[span-key-literal-table]`: AGENTS.md's `| Test file | Span-key literals | Why |` table read like
  `[not-callable-pin-table]` (a missing table, a malformed row and a repeated row each fail), compared with the budget
  in both directions.
- The header list gains one sentence after the twelfth: the thirteenth, `SPAN_KEY_LITERAL_BUDGET`, is test-scope like
  `METRIC_ID_LITERAL_BUDGET`, and it and `[span-key-source]` are described where they run (ADR-QD-188).
