Design recorded (owner: choose the most complete and clean design and record why):
- The order is D-04's, written as two guarded reads and a fallback: read the `message` only of an `Error` (a plain
  `{ message }` object stays its `String` form, as every site renders it today), return it if it is a string; else
  return `String(thrown)` if that does not throw; else the placeholder. One `try` per read, so a throwing `instanceof`
  (a proxy's `getPrototypeOf` trap) is guarded too. The placeholder is a module constant, as `ValueText.ts` keeps
  `NO_JSON_FORM`.
- `describeThrown` and `renderReason` are deleted rather than kept as aliases: one name for one rule.
- `causeMessage` (D-14) sits in the same module as `thrownMessage`, because the two are one rule: what a reader sees of
  something that went wrong. `Cause.pretty` throws for a cause that failed or died with a value whose `message` getter,
  `toString` or proxy traps throw (probed on the installed `effect` 4.1.2 by the plan check), so it is called inside a
  `try` whose empty `catch` falls through to `thrownMessage(Cause.squash(cause))`. `Cause.squash` returns the failed or
  died value itself, so the fallback text is the same rule as a caught value. A cause that renders keeps its
  `Cause.pretty` text, which every existing pin of a rendered defect or failure keeps. The module imports
  `effect/Cause` only; neither function is an Effect.
- `customPredicatePort.defect` calls `causeMessage` rather than a private guard of its own: one rule, one place (D-14
  replaces the private guard D-05 first named).
- `PortWireEncode`'s catch arms take `thrownMessage` point-free (`catch: thrownMessage`).
- The overview rows and the source doc comments cite ADR-QD-182 as plain text (no link): 69-07 lands the ADR file in this
  phase, and no gate resolves a plain ADR id (verify-traceability check 5 resolves links only).

Shell and commit rules: as in 69-01's objective. Never write the inline Error-or-String ternary, the old
angle-bracketed placeholder or `Cause.pretty` followed by an opening parenthesis in any comment: the negative gates
below count comment lines.
