## The five rule sentences

Written here once; every later text that states one of these rules (doc comments in 74-03 and 74-04, BEH-QD-706 to
BEH-QD-710 and INV-QD-393/394 in 74-06) copies the sentence verbatim, backticks included. The plain forms (backticks
dropped) are what the checks compare.

1. Pin: "The constructor, `withSightings` and `seedFrom` each pin the head exactly when no replayed policy is held, and
   `choose` holds a value and pins nothing."
2. Orphan: "While a replayed policy is held, the seed is its row; otherwise a row that is not a `TimelineDecision`
   stays the baseline row, and a decision row the reviewer walked away from is no seed."
3. Menu: "The menu is one list of entries, each with its value, its label and the sighting it names, and `menuOf` and
   `sightingAt` both read it, so a position that names no sighting answers nothing."
4. No-op: "`choose` returns its input when no replayed policy is held and the held sighting has the chosen policy, and
   the session publishes nothing only when `choose` returned its input and the run is `Idle`."
5. Draft and run: "Once the session is built, `writeDraft` is the one place the draft and its resource text are
   assigned, and `clearRun` is the one operation that stops the run in flight and sets it `Idle`, called from
   `reseed`, `choosePolicy` and `setPorts`."

And the reference rule, copied the same way: "A transition that changes nothing returns its input object, so a caller
detects a no-op with `===`."

  calls `replayInput` once and answers the next choice with the input the session writes as its draft (a `Seeding`),
  and the constructor answers the same, so replay is decoded in one place. (7) `PolicyChoice`, `PolicyMenu` and
  `PolicyMenuOption` are declared in `SeededChoice.ts`; the barrel names them from there, under the same names. (8)
  the session holds one `let choice: SeededChoice` and keeps only runs and the form; `stale` stays in the session.
  (9 and 10) sentence 5, with `start`'s `Refused` path still calling `supersede` because it sets `Refused`, not `Idle`.
