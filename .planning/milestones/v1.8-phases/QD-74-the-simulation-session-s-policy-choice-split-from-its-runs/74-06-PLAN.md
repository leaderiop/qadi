## The invariants (Task 1)

- `## INV-QD-393: The simulator's seeded choice is a pure value`. Statement: `SeededChoice.ts` holds which policy the
  simulator runs and where it came from as an immutable value; its transitions return their input for a no-op, the pin
  rule lives only inside them, and the menu's order is stated by one list that both the menu and its reverse lookup
  read; then the reference rule verbatim. Source: `packages/devtools/src/model/SeededChoice.ts` (the transitions, the
  readings, `pinUnlessReplayed`, `menuEntries`, `menuLead`). Implication: a rule is a value a test reads with no scope,
  and the menu and the lookup cannot disagree on a position (ADR-QD-187, ADR-QD-047). Enforcement: the compiler
  (`SeededChoice.tst.ts`, "the first three arms of PolicyChoice are HeldChoice of PolicySighting", "every transition
  answers a seeded choice, so a no-op can return its input"), tests (`SeededChoice.test.ts`, citing the 706 to 709
  titles from it), and review alone for "the pin rule lives only inside the transitions", since no gate counts the
  callers of `pinHead`. Related: ADR-QD-187, ADR-QD-047, INV-QD-107, BEH-QD-706 to BEH-QD-709.
- `## INV-QD-394: The simulation session writes its draft in one place and clears its run through one operation`.
  Statement: rule sentence 5 verbatim. Source: `packages/devtools/src/model/SimulationSession.ts` (`writeDraft`,
  `clearRun`). Implication: the no-op rule and the resource-text rule are written once, and a run in flight is stopped
  the same way by every command that clears it (ADR-QD-187, ADR-QD-150, BEH-QD-322). Enforcement: tests only, the
  characterisation `packages/devtools/test/model/SimulationSession.characterisation.test.ts` (the 710 titles); that the
  draft, its text and an `Idle` run are assigned only there is kept by review and not by a test or a gate. Related:
  ADR-QD-187, ADR-QD-137, ADR-QD-150, BEH-QD-710, BEH-QD-322.
