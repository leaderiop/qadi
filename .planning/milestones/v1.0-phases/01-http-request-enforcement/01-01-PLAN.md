Typing fact measured during planning (scratch probe against effect@4.1.2, tsc): `Effect.catchTag(TAGS, f)`
over a handler error typed by a constrained type parameter (`EH extends HttpEnforcementFailure | unhandled`)
fails with TS2345 ("not assignable to ... Tags<EH>"); an overload pair (closed `HttpEnforcementFailure`
→ projection error only; `HttpEnforcementFailure | unhandled` → projection error | unhandled) whose
implementation is typed at the wider union compiles with no cast, and callers get exactly the narrow type.

and the unguarded-port call. Zero errors; a negative control (claiming the middleware's error is `never`)
