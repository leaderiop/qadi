<objective>
Collapse the dock's snapshot hooks into the one store-snapshot hook 34-03 introduced (D-14): delete the keep-alive readers
that passed a constant-`undefined` run to `useRunningStore` (`useDockSnapshot`, `useExplorerSnapshot`,
`useHeldChoiceSnapshot`), move `usePaused` beside `useStoreSnapshot`, and read the simulation session through it too.

places. A read that forks nothing should not go through a helper whose job is forking; after this plan the only reader is
`useStoreSnapshot`, and `useRunningStore` has one caller left (`useDiagnostics`, which 34-06 rebuilds).

Output: `usePaused` in `react/useStoreSnapshot.ts`; `useDockSession.ts` and `useExplorerSession.ts` deleted; four
components and hooks reading through `useStoreSnapshot`; `test/react/useStoreSnapshot.test.tsx` (S1..S3).

## Flagged assumptions

- **`usePaused` is a store snapshot.** `{ subscribe: timeline.subscribe, getSnapshot: timeline.isPaused }` is a
  `Pick<ExternalStore<boolean>, …>`: one subscription to the timeline, and `isPaused` returns a primitive, so React's
  snapshot comparison is exact. D-14's fallback (a stated second `useSyncExternalStore`) is therefore not taken.
- **The simulation session's public reads move too.** D-14 names the dock's hooks; `useSimulationSnapshot` and the owned
  hook's private read are the same one-line read of a store, so leaving them would keep three copies of the line the hook
  exists to hold. Their signatures and behaviour are unchanged. Reversible.
