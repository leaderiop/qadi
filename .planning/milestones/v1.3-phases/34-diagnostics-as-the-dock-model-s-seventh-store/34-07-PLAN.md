## Flagged assumptions

- **`isUnsampled` lives in the model, not in `DiagnosticsNotice.tsx`.** The UI contract places it in the notice file;
  34-02 put it in `model/DiagnosticsFeed.ts`, because `stryker.devtools.mjs` mutates only `model/**`, so the predicate the
  suppressions depend on is mutation-measured there. Same signature, same arms; the two screens still call one function.
- **The alert mode is decided per mount and per new stop value.** The UI contract decides it in a `useState` initializer at
  mount. A restart whose fork dies in its synchronous prefix publishes `Starting` and a new `Stopped` in one tick, which React
  may render as one `Stopped` to `Stopped` change with the notice still mounted; the notice therefore also re-decides when
  `status` changes identity (the adjust-state-on-prop-change pattern: the previous status held in state, compared during
  render). Same behaviour as the contract in every case it lists.
- **The tracer touches six files**, two of them mechanical (`liveNotice` in `test/helpers.ts`, and the prop insertion in
  `ServicesPanel.test.tsx` that the required prop forces). Splitting them off would leave a commit that does not typecheck.
