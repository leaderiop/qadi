   - `## Decision`: `SinkWire.ts` exports `WIRE_VERSION = 2 as const`, the version `encodeSinkRecord` writes and the one place the number is written in that code; `WIRE_VERSIONS = [WIRE_VERSION] as const`, typed `readonly [2]`, is the read set, a separate idea from the write version (a reader that keeps an older version lists it there beside a schema for it, while `WIRE_VERSION` moves alone); `WireVersion = (typeof WIRE_VERSIONS)[number]`, kept as `UnsupportedVersion.supported`'s element type. `SinkCodec.ts` reads them: `Schema.Literal(WIRE_VERSION)` in both field structs, `version: WIRE_VERSION` in the encoder, and a read check that is membership in `WIRE_VERSIONS` through a `Schema.is(Schema.Literals(WIRE_VERSIONS))` guard, never a comparison with `WIRE_VERSION`.
