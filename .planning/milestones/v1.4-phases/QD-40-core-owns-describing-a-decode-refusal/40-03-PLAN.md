## Flagged assumptions

- **Placement is SinkWire.ts, all three readers** (D-08): the import graph allows a type-only edge to
  `UntrustedDecode.ts` (RESEARCH Q2), so no "nearest module" fallback is needed. `decodeRefusalOf`'s parameter type is
  written inline, `UntrustedRefusal | Extract<DecodeRefusal, { readonly _tag: "UnsupportedVersion" }>`, so no unexported
  alias appears in a public signature.
- **The bounded description (CONTEXT discretion):** a version string is shown as `JSON.stringify` of its first 40 UTF-16
  code units, then `…` if cut; a number or boolean as `String(value)` (never user code); `none` for undefined, `null` for
  null; `an object`, `a function`, `a bigint`, `a symbol` otherwise (an array is `an object`: `Array.isArray` throws on a
  revoked Proxy). A message is cut at 200 code units, then `…`. `SHOWN_VERSION_CHARS = 40` and `SHOWN_MESSAGE_CHARS = 200`
  are module-scope, so `ignoreStatic` hides them; the boundary rows guard them.
- **The five sentences (CONTEXT discretion), each naming the reason and its fix**, exactly:
  - `NotJson`: `not JSON: the text did not parse, so something between the sender and this reader truncated or replaced it`
  - `TooDeep`: `nested deeper than <maxDepth> levels: a current sender refuses to emit that, so the sender is older or foreign`
  - `Malformed`: `not a record this reader can read, so the sender and this reader disagree about the wire form: <shown message>`
  - `Inconsistent`: `a record that contradicts itself (<disagreement>): built by hand or tampered with, not version skew`
  - `UnsupportedVersion`: `a record of wire version <shown version>, which this reader does not read (it reads <supported joined by ", ">): upgrade the reader if the version is newer, or the sender if it has none`
- **SinkWire.ts's mutation score was 1 with no scored mutant at the base.** The describer's handler bodies and
  `shownVersion` run per call, so they are scored after the change; every one must be killed for the score not to fall.
  The tables below are written to kill each branch and each boundary; 40-09 closes any survivor with a test.
