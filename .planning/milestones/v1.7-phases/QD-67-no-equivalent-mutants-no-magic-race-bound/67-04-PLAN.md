### File: mutate.py

````python
# python3 mutate.py <file> <old> <new>: replaces the one occurrence of <old> with <new>; fails unless it occurs once.
import sys
p, old, new = sys.argv[1], sys.argv[2], sys.argv[3]
s = open(p).read()
n = s.count(old)
if n != 1:
    sys.exit(f"{p}: {n} occurrences of {old!r}")
open(p, "w").write(s.replace(old, new))
````
