<objective>
Replace `DecisionCache`'s eviction loop with one split and one removal, so it has no branch a cache cannot take
(MUTE-01, WX-04, WX-06; 67-CONTEXT "Eviction"). The loop's `Option.isSome(oldest)` guard could not be false while the
loop ran, so its mutant was equivalent. `Chunk.splitAt(insertionOrder, HashMap.size(entries) - options.capacity)` takes
exactly the overflow and nothing when there is none, since it reads a count of zero or below as zero (67-01 P1);
`HashMap.removeMany` removes those keys, and the kept half is the new order. `import * as Option` goes with it, the
file's only other use. The comments above the eviction, above `insertionOrder` and in the `capacity` doc are rewritten to
what the new code holds, and `TraceDiff.ts`'s comment drops its comparison with the guard, which no longer exists.

Purpose: the eviction's only survivor is removed rather than suppressed, before the dispatch changes, so the Stryker
close in 67-07 sees both changes against one base.
